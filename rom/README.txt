Metti qui dentro i tuoi file ROM e le copertine.

Esempi:
- pokemon-giallo.gbc
- pokemon-giallo.jpg
- mario-kart.gba
- mario-kart.png

Una volta messi i file, fai doppio click su 'CARICA-ROM-SU-GITHUB.bat' (nella cartella principale),
oppure scrivi all'assistente "Ho inserito i file, sincronizza!".

I tuoi file saranno immediatamente disponibili online su:
https://rivegabry.github.io/emulatore-nfc/roms/nome-del-file.gbc
